    MCPサーバーからスキルを配る「Skills over MCP」の使いどころ　チームの手順書はサーバーの SKILL.md を1か所直せば全員に届く

    Zennの解説記事（11/25）は、Skills over MCPを「社内ポータルに業務マニュアルを置き、各自がコピーしなくても最新版を開ける」仕組みと説明しています。同じリポジトリで作業するチームは .claude/skills/ にコミット、ワークスペースが別々でも手順を揃えたいチームはMCPサーバーに置く、一人で使うなら手元のフォルダ、という使い分けを表で整理しています。Claude Code v2.1.331以降が必要で、FastMCPならスキルのフォルダ（name と description を書いた SKILL.md）を公開するだけで配れます。MCP経由のスキルでは allowed-tools などの一部の設定や「!」コマンドが無視される点も公式ドキュメントに書かれています。

    Zenn（shogo_h）zenn.dev →

    Claudeのアーティファクトをアプリとして入れる手順　タイトルのメニューか右クリックで「アプリとしてインストール」、権限は必要な分だけ

    使ってみたAIラボ（11/25）は公式ヘルプをもとに手順を4段階で整理しています。Claude Desktop（Mac・Windows、6.28899.0以降）でアーティファクトを開き、タイトルのメニューか右クリックで「アプリとしてインストール」を選び、確認画面で「インストール」を押すだけです。Free・Pro・Max・Ultraでも段階的に使え、Macはアプリケーションの「Claude Apps」、Windowsはスタートメニューから開けます。Web版・スマホ・Linuxでは使えず、アプリの利用分もプランの上限に数えられます。最上位の「このコンピュータへのフルアクセス」は確認なしでファイル削除までできるため、中身を確かめたアプリにだけ許可するよう勧めています。

    使ってみたAIラボtsukatte-ai.com →

    ChatGPTの音声入力が話しながら文字に　10分の上限も撤廃、長い指示を口で話して直してから送れる

    CNET Japanによると、OpenAIは11/18、話した内容を入力中にリアルタイムで文字にする「Live Dictation」を発表し、音声入力の10分上限もなくしました。無料プランを含む全プランで、iOS・Android・Web・デスクトップに順次提供されます。入力欄のマイクを押すと録音と文字起こしが始まり、波形をタップすると表示を切り替えられます。文字になった文章は送信前に編集できるので、長い指示を口頭で吹き込み、確認・修正してから送る使い方ができます。

    CNET Japanjapan.cnet.com →

    CodexのAGENTS.mdの書き方　自分用は ~/.codex、プロジェクト用は各フォルダ、まず /init で下書き

    株式会社Pdienの解説（11/19）は、AGENTS.mdをCodexが作業前に必ず読む指示書と説明しています。自分用は ~/.codex/AGENTS.md、プロジェクト用は各フォルダに置き、上の階層から順につなげて読まれ、作業中のフォルダに近いほど後に読まれて優先されます。合計は既定で32KiBまでです。最初は /init で下書きを作り、テストやlintのコマンド、禁止事項、完了条件などを自社の決まりに合わせて書き直すのがコツで、Cursor・Gemini CLI・GitHub Copilotなども同じファイルを読みます。

    株式会社Pdienpdien.co.jp →

    Geminiの「チャット」と「タスク」の使い分け　時間のかかる調べもの・毎朝のまとめ・値下がり監視はタスクに

    AIみちしるべは、Geminiアプリの入力欄を「Chat」から「タスク」に切り替える新機能を、公式ヘルプとリリースノート（11/17）をもとに整理しています。すぐ答えがほしい質問や文章の手直しはチャット、時間のかかる調査、毎朝の予定とメールのまとめ、値下がりや新着の見張り、PDF・Word・Excel・PowerPointでの受け取りはタスク向きです。タスクは同時に最大15個まで動かせ、日本では18歳以上の個人アカウントなら無料で使えます。
