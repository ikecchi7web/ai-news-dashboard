    Geminiの「タスク」を無料で始める3ステップ　「チャット→タスク」に切り替え、目標・期限・仕上がりの形を書いて送る

    日本でも無料になったGeminiの「タスク」の使い方を整理した記事です。①入力欄の近くの切り替えを「タスク」にする（スマホは入力欄の上、Web版は下）、②「何を・いつまでに・どんな形で」仕上げてほしいかを書いて送る、③メール送信やファイル変更など確認が必要な場面で止まるので、内容を見て承認する、の3ステップ。何を書けばよいか迷ったら「interview me」と送ると質問形式で進められます。毎朝8時のニュース要約のような定期実行もでき、同時に動かせるのは15件まで。仕事用・学校用のアカウントは今は使えず、Geminiの「履歴」をオンにしておく必要がある点に注意です。

  2. 2

    Claude CodeからCodexを呼んで見直させる　公式プラグインを4つのコマンドで入れ、/codex:reviewで二重チェック

    OpenAI公式のプラグインを使い、Claude Codeの入力欄から4つのコマンド（/plugin marketplace add openai/codex-plugin-cc → /plugin install codex@openai-codex → /reload-plugins → /codex:setup）を順に打つだけで連携できます。使い分けは、ふつうの見直しが/codex:review、作り方や前提を疑う厳しめの見直しが/codex:adversarial-review（確かめたい決まりを後ろに書き足せる）、作業ごと任せるのが/codex:rescue。見直しの2つはファイルを書き換えません。「codex mcp-serverでつなぐ」古い手順はコマンドが削除済みなので注意。終わるたびに自動で見直させるReview Gateは、利用上限を早く使い切るおそれがあるため、見ていられる時だけ有効にするのがコツです。

    スマートエイトsmart-eight.jp →
  3. 3

    CodexとClaude Codeを併用するなら、決まりはAGENTS.mdに1本化　CLAUDE.mdには「@AGENTS.md」の1行だけ

    2つのAIで指示書を別々に直すと片方が古くなりがち、という悩みへの実践手順です。共通の決まり（テストのコマンド、触ってよいファイルなど）はAGENTS.mdに書き、CLAUDE.mdには「@AGENTS.md」とClaude Code専用の決まりだけを置きます。逆にCodexに既存のCLAUDE.mdを読ませたいときは、~/.codex/config.tomlに project_doc_fallback_filenames = ["CLAUDE.md"] を1行足す方法も。スキルは .agents/skills にまとめ、.claude/skills をそこへのリンクにすると両方が同じスキルを使えます。Claude Codeの直しを「codex review --uncommitted」で見直させる頼み方の例文も載っています。

    AInformationainformation.jp →

    CodexのモデルはGPT-6.2 SolとAstraをどう選ぶ？　普段の修正はSol、大きな修正や難しい調査はAstra

    Codexに来た新モデルの選び方と切り替え方をまとめた記事です。日々のコード修正・見直し・資料の整理はコストの軽いGPT-6.2 Sol（Astraの約5分の1）、サービスをまたぐ不具合の追跡や大がかりな修正・テスト、難しい調べものはGPT-6.2 Astra、という分け方が基本。切り替えは対話中なら/modelで、コマンドで始めるときは codex --model gpt-6.2-sol のように指定します。まずSolで進め、詰まったところだけAstraに上げると、利用枠を節約しながら質も保てます。

    ChatGPTの使い方、仕事でそのまま使えるプロンプト例つき　[ ]を差し替えるだけでメール・議事録・集計・スライドまで

    ChatGPTを無料で始める手順（ブラウザ・スマホ・デスクトップアプリ）と、仕事で使える頼み方の例をまとめたガイドです。日程変更のメール、会議の録音からの議事録（決定事項・課題・次の作業）、長い資料の要点5つ、表の月別集計とグラフ、deep researchでの競合調査など、[ ]の中を自分の内容に変えるだけで使えるプロンプトが並びます。毎週の報告のように同じ前提を何度も使う仕事は「プロジェクト」にまとめ、「資料にない数字は書かない」「分からない点は書く前に質問する」と指示しておくのがコツ。回答の中身は必ず自分で確かめるよう添えられています。
