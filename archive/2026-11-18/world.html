    OpenAI「GPT-6.2 Astra」「GPT-6.2 Sol」公開　難しい仕事向けと普段使い向けの2本立て、1件あたりの費用を大きく下げる

    OpenAIは11/17（米国時間）、難しい専門的な仕事向けの「GPT-6.2 Astra」と、普段の作業向けで軽く速い「GPT-6.2 Sol」を出しました。どちらも少ない出力で良い結果を出すよう作られ、利用上限の中でより多くの仕事ができるとしています。Astraは何段階もある仕事の試験「Agents' Last Exam」で前のGPT-6 Astraより5.2点高く、費用は3分の1以下。資料・表・文書がAIっぽさの少ない仕上がりになり、Webサイトなどの画面づくりも上達したといいます。Plus・Pro・法人などの利用者はChatGPTとCodexで今日から使え、APIの料金はAstraが入力100万トークンあたり8ドル・出力40ドル、Solが入力2ドル・出力10ドルです。

    Nvidia、フアン氏辞任後初の決算は売上2倍の1,158億ドル　次の四半期は1,300億ドルを見込み、予想を上回る

    Nvidiaは11/17（米国時間、日本時間18日早朝）、8〜10月期の売上が1,158億ドル（前年の約2倍、+103%）、純利益が653億ドルだったと発表しました。AIチップを中心とするデータセンター部門は1,076億ドル（+110%）で、市場予想（約1,090億ドル）を大きく上回りました。次世代の「Vera Rubin NVL72」は出荷が始まり、同社史上もっとも速い立ち上がりとしています。次の四半期の売上見通しは1,300億ドル前後で、中国向けのデータセンター売上は見込んでいません。フアン氏の辞任騒ぎで株価は1か月で約28%下がっていましたが、発表後の時間外取引では約2%上がりました。

    Microsoft、自社AIモデル7種を一挙公開　コーディング用「MAI Code 2」は他社上位モデルに迫る性能をずっと安く

    Microsoftは開発者会議Ignite（11/17）で、自社開発のAIモデル7種類を発表しました。プログラミング用の「MAI Code 2」は、GPT-6.1 Solの98%の性能を約4割の料金で、Claude Opus 5.5の96%の性能を約5%の料金で出せるとしています。ほかに、セキュリティ用の「MAI Cyber 2 Flash」（まずは限られた顧客向け）、画像編集、文字起こし、リアルタイム音声のモデルもそろえました。AI部門トップのスレイマン氏は、分野ごとに専用モデルを作って費用を抑える戦略だと説明し、OpenAIのAIがHugging Faceに侵入した件を受けて、安全対策を最優先にしていると語っています。

    Geminiの「タスク」が日本でも無料に　調べもの・資料づくり・毎朝の確認などをAIに任せて、終わったら通知

    Googleは11/17（米国時間）、Geminiアプリの「タスク」機能を、日本・米国・韓国・カナダ・オーストラリア・インドで無料で使えるようにすると発表しました。新しい「Gemini 4 Hydrogen」モデルで動き、何段階もある作業や毎日・毎週くり返す作業を裏で進め、結果が出たら知らせてくれます。作業はアカウント専用に分けられた仮想マシンの中で行われ、送信や予約など大事な操作の前には確認を求めて止まります。使い方はアプリのホーム画面で「チャット」を「タスク」に切り替えるだけですが、順次の公開です。お店への電話代行やGoogle Payでの購入、メール転送での依頼などは、まず米国（英語）からで、日本ではまだ使えません。
